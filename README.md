# 감옥탈출

감옥탈출류 마우스 피하기 팬 게임. 죄수가 커서를 따라다니고, 함정에 닿으면 즉사하고,
출구에 닿으면 다음 방으로 간다.

만드는 도구가 없다. `npm install`도 빌드도 안 한다 — 브라우저와 node만 있으면 된다.

## 돌리기

```
npm start
```

그리고 http://localhost:8173 을 연다. ES 모듈이라 파일을 그냥 두 번 눌러 여는 건 안 된다.

| 주소 뒤에 | 하는 일 |
|---|---|
| `?room=2` | 2번 방부터 시작한다. 방을 짜는 동안 쓴다 |
| `?mute=1` | 소리를 끄고 시작한다 |

| 키 | 하는 일 |
|---|---|
| H | 판정을 빨간 선으로 보여준다. 함정을 놓을 때 켠다 |
| M | 소리를 껐다 켠다 |

## 검사

```
npm test
```

규칙이 화면을 모르는 순수 함수라 브라우저 없이 다 검사된다. 1초 안에 끝난다.

## 방 추가하기

`src/data/rooms.js`에 덩이를 하나 더 넣는다. **코드는 안 건드린다.**

방 하나는 960×720이다. 왼쪽 위가 0,0이고 y는 아래로 커진다.

```js
{
    name: '세탁실',
    spawn: { x: 480, y: 690 },          // 시작 자리
    exit: { x: 440, y: 0, w: 80, h: 46 },  // 여기 닿으면 다음 방
    hazards: [ ... ],                    // 닿으면 죽는 것
    props: [ ... ],                      // 판정 없는 장식
}
```

함정은 네 가지다.

| 종류 | 쓰는 값 | 하는 일 |
|---|---|---|
| `rect` | `x y w h` | 가만히 있는다. 벽과 철창 |
| `blink` | 위 + `period on` | `period`초마다 `on`초 동안만 죽인다. 전기 |
| `mover` | 위 + `dx dy period` | 제자리에서 그만큼 왕복한다 |
| `cone` | `x y radius spread from to period` | 간수의 시야. 각도는 0이 오른쪽, 90이 아래쪽 |

`offset`을 주면 시작 박자가 그만큼 밀린다. 함정 여럿이 같이 움직이는 걸 어긋나게 할 때 쓴다.

`art`에 이름을 적으면 그 그림으로 그린다. 안 적으면 색 도형으로 그린다.

방을 넣고 `npm test`를 돌린다. **시작 자리가 안전한지, 출구에 설 수 있는 순간이 있는지**를
검사가 대신 봐준다 — 깰 수 없는 방을 만들어두고 모르는 일이 안 생긴다.

## 그림 넣기

`art/` 폴더에 png를 넣으면 끝이다. 이름은 `src/view/art.js`에 적혀 있다.

```
art/player.png   죄수      art/wall.png    벽 (반복)
art/guard.png    간수      art/fence.png   철창 (가로로 반복)
art/spark.png    전기      art/bar.png     오가는 장애물 (가로로 반복)
art/exit.png     출구      art/muscle.png  art/drain.png  art/toilet.png ...
```

투명 배경 png, 화면 크기의 2배로 그려서 내보내면 된다.

**파일이 없으면 색 도형으로 대신 그린다.** 한 장씩 넣어도 되고, 안 넣어도 게임은 돈다.
그림을 넣어도 게임 코드는 안 바뀐다 — 판정은 도형이 따로 갖고 있다.

그래서 **브라우저 콘솔에 없는 png만큼 404가 뜬다. 고장이 아니다.** 그림을 다 넣으면 사라진다.

간수의 빨간 시야, 전기가 켜지고 꺼지는 것, 죽음 화면은 코드가 그린다. 안 그려도 된다.

## 소리 바꾸기

`audio/` 폴더의 파일을 갈아끼운다. 지금 들어 있는 것은 Re 프로젝트에서 가져왔다.

```
click.mp3  수감 버튼     death.mp3  죽을 때
clear.mp3  방을 깼을 때  win.mp3    다 깼을 때     bgm.mp3  배경음
```

## 어디에 무엇이 있나

```
src/rules/     규칙. 화면도 시간도 모른다. 여기만 검사하면 게임이 검사된다
  geometry.js    도형이 겹치는가
  hazards.js     시간을 넣으면 함정이 지금 어떤 모양인가
  room.js        죽었는가, 도착했는가
src/data/rooms.js   방 목록. 방을 늘리는 곳
src/view/      그리기와 소리. 규칙을 안 바꾸고 보여주기만 한다
src/main.js    화면 넘김과 진행
test/          검사
```
