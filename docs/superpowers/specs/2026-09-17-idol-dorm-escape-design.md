# 숙소탈출 — 설정 교체와 방 6개 설계

2026-09-17

앞선 설계(`2026-09-16-prison-escape-design.md`)를 잇는다. 규칙층은 그대로 두고
**설정을 갈아끼우고, 함정 세 가지를 얹고, 방을 6개로 늘린다.**

---

## 1. 설정이 바뀌었다

감옥이 아니다. **주인공은 아이돌이고, 숙소에서 몰래 빠져나와 감시망을 피해
편의점에 간식을 사러 간다.**

규칙은 한 줄도 안 바뀐다. 게임이 보는 것은 여전히 반지름 7짜리 원 하나와
죽는 도형 몇 개뿐이다. 간수의 시야든 회전 CCTV든 판정은 같은 부채꼴이다.
**설정 교체의 값이 이렇게 싼 것이 그림과 판정을 분리해 둔 덕이다.**

| 전 | 후 |
|---|---|
| 죄수 | 아이돌 |
| 간수 시야 `cone` | 매니저 시선 · 회전 CCTV |
| 전기 `blink` | 동작 감지 센서 · 깜빡이는 복도등 |
| 오가는 장애물 `mover` | 청소 카트 · 순찰 경비 |
| 철창 `fence` | 잠긴 문 · 난간 |
| 즉사 | **들킴** — 숙소로 되돌아간다 |
| 죽은 횟수 | **들킨 횟수** |
| 마지막 출구 | **편의점 문** |

### 수감 카드를 없애고 타이틀 → 연출 → 시작으로 바꾼다

이름과 죄목을 적던 시작 화면을 지운다. 아이돌 설정에 죄목이 들어갈 자리가 없다.

세 화면으로 나눈다.

```
타이틀        제목과 [게임 시작]
  ↓
연출          "새벽 2시. 다들 잔다." + 중앙 하단에 [문을 연다]
  ↓
플레이        버튼이 있던 그 자리에서 아이돌이 시작한다
```

**연출 화면의 버튼은 1번 방의 시작 좌표 위에 정확히 올린다.** 누르는 순간 커서가
이미 시작 자리에 있으므로, 아이돌이 엉뚱한 곳에서 튀어나와 죽는 일이 없다.

이것이 지금의 `READY_RADIUS`(커서를 시작 자리로 끌어오기)와 같은 문제를 푼다.
다만 플레이어에게는 규칙이 아니라 그냥 버튼으로 보인다. 설명할 것이 없어진다.

`READY_RADIUS`는 **지우지 않는다.** 방과 방 사이, 그리고 들킨 뒤 다시 시작할 때는
커서가 이미 화면 안에서 움직이고 있다. 거기서 클릭을 요구하면 마우스 피하기의
흐름이 매번 끊긴다. 첫 진입만 버튼이고 나머지는 지금대로 커서를 옮기면 된다.

버튼을 아예 없애서는 안 된다. 이 버튼이 실은 **브라우저가 소리를 틀도록 허락받는
첫 사용자 입력**이기도 하다. 자동 재생 정책 때문에 클릭 없이 시작하면 배경음이 안 나온다.

1번 방의 시작 자리를 화면 중앙 하단(`480, 648`)으로 옮긴다. 연출 화면의 버튼이
거기 놓이고, 검사가 그 자리가 안전한지 본다.

### 이야기의 순서

방 배치는 이미 검사를 통과했고 브라우저에서 손맛도 봤다. **좌표는 손대지 않고
이름과 그림만 갈아끼운다.** 뒤에 세 개를 이어 붙인다.

| # | 전 | 후 | 새로 나오는 것 |
|---|---|---|---|
| 1 | 운동장 | 숙소 라운지 | (튜토리얼) |
| 2 | 복도 | 기숙사 복도 | |
| 3 | 감시탑 | 로비 | |
| 4 | — | 지하 주차장 | **돌아가는 차단바** |
| 5 | — | 밤거리 골목 | **순찰 도는 경비** |
| 6 | — | 편의점 앞 | **안 보이는 함정** + 전부 |

## 2. 함정 세 가지

### ① 순찰 간수 — `cone`을 넓힌 것. 새 종류가 아니다

`cone`에 `dx`/`dy`를 더하면 시야의 주인이 왕복한다.

```js
const look = pingPong(t + (offset ?? 0), period);
const walk = pingPong(t + (walkOffset ?? 0), walkPeriod ?? period);
```

**고개와 발의 주기를 따로 둔다.** 같은 값을 쓰면 "오른쪽으로 갈 때는 늘 오른쪽을
본다"가 되어 안전한 쪽이 고정되고, 방이 한 번 보면 끝나는 것이 된다.
주기가 어긋나야 지나갈 때마다 다른 그림이 나온다.

`dx`/`dy`가 없으면 계산 결과가 기존과 완전히 같다. **기존 방 셋과 검사 27개가
그대로 통과한다.**

그리는 쪽은 **한 줄도 안 고친다.** `drawCone`이 이미 원본 데이터가 아니라
`shapeAt`이 돌려준 "지금 도형"의 `x`/`y`를 보고 있어서, 데이터가 움직이면
시야도 몸통도 알아서 따라간다.

### ② 돌아가는 차단바 `spinner`

```js
{ kind: 'spinner', x, y, length, thickness, period, offset }
```

`x, y`가 축이고 막대는 그 **중심**을 축으로 돈다. 각도는 왕복이 아니라 한 방향으로 계속:

```js
angle = 360 * (t + (offset ?? 0)) / period      // period가 음수면 반대로 돈다
```

`pingPong`이 아닌 시간 함수가 처음 생기는 자리다. 그래도 **시간만 넣으면 모양이
정해진다**는 성질은 그대로라서, 되감아도 건너뛰어도 같은 답이 나온다.

판정은 새 도형 `obb`(기울어진 사각형)다. **기하 함수를 새로 짜지 않는다.**
원의 중심을 막대의 좌표계로 역회전시키면 그 순간 축 정렬 사각형이 되어
기존 `circleHitsRect`를 그대로 쓸 수 있다.

```js
export function circleHitsOrientedRect(cx, cy, radius, box) {
    const a = -box.angle * Math.PI / 180;
    const dx = cx - box.x, dy = cy - box.y;
    const lx = dx * Math.cos(a) - dy * Math.sin(a);
    const ly = dx * Math.sin(a) + dy * Math.cos(a);
    return circleHitsRect(lx, ly, radius,
        { x: -box.w / 2, y: -box.h / 2, w: box.w, h: box.h });
}
```

`rect`를 `obb`의 특수한 경우(각도 0)로 합치지는 않는다. 벽 하나 판정할 때마다
사인·코사인을 부르게 되고, 잘 돌고 있는 검사를 다 건드려야 한다. 값이 안 맞는다.

### ③ 안 보이는 함정 `hidden`

아무 함정에나 `hidden: true`를 붙인다. **판정은 살아 있고 그림만 안 그린다.**
`render.js`의 `drawHazard`가 맨 앞에서 한 번 걸러내면 끝이다.

이것이 거의 공짜인 것도 그림과 판정을 갈라 둔 덕이다. 게임은 애초에 그림이
있는지도 모르므로, 그림을 빼도 게임에게는 아무 일도 일어나지 않는다.

#### 당하고 나면 보인다

"그냥 안 보이는 함정"으로 끝내면 농담이 아니라 사고다. 고양이 마리오가 재미있는
까닭은 안 보여서가 아니라 **당하고 나면 알게 되기 때문**이다. 끝까지 안 보이면
배울 것이 없고 그냥 운이 된다. 그래서:

> 나를 들키게 한 숨은 함정은, 그 방에 있는 동안 계속 보인다. 방을 깨면 잊는다.

이 기억을 함정에 들리면 설계 금기(함정은 상태를 갖지 않는다)를 깬다. 그래서
**기억은 진행층이 든다.**

- `stepRoom`이 `dead` 옆에 `killedBy`를 하나 더 돌려준다. 나를 죽인 함정의
  **방 안 번호**다. 안 죽었으면 `-1`. 여전히 순수 함수다
- `main.js`가 그 번호를 `Set`에 모아 `drawRoom`에 넘긴다.
  방에 들어설 때 `Set`을 비운다

`H`(판정 보기)를 누르면 숨은 함정도 전부 빨간 선으로 보인다. 방을 짤 때 필요하다.

#### 숨은 함정을 놓는 규칙

지키지 않으면 재미가 아니라 화가 난다. 검사가 대신 본다.

1. **시작 자리에서 90px 안에는 두지 않는다.** 들어서자마자 보이지 않는 것에
   죽으면 뭘 잘못했는지 알 수 없다
2. **마지막 방에만 둔다.** 배울 것을 다 배운 뒤라야 농담이 된다
3. **숨은 함정 하나를 피하는 길이 반드시 있다.** 기존 "출구에 설 수 있는
   순간이 있는가" 검사가 자동으로 본다

브라우저를 요구하게 된다.

## 4. 검사

기존 27개는 그대로 통과해야 한다. 하나라도 깨지면 설정 교체가 규칙을 건드린 것이다.

새로 더하는 것:

**기하**
- 기울어진 사각형이 각도 0일 때 축 정렬 사각형과 같은 답을 낸다
- 45도로 돌린 막대의 모서리 바깥·안쪽
- 막대 끝 너머는 안 닿는다

**함정**
- `spinner`가 한 주기 뒤에 처음과 같은 각도로 돌아온다
- `spinner`의 각도가 시간에 비례해 는다. `period`가 음수면 반대로 돈다
- `dx` 없는 `cone`은 기존과 완전히 같은 값을 낸다 *(회귀)*
- 걷는 주기와 보는 주기가 다르면 위치와 각도가 따로 논다

**방**
- 숨은 함정은 시작 자리에서 90px 밖에 있다
- 숨은 함정은 마지막 방에만 있다
- 방이 6개다

**진행**
- `killedBy`가 나를 죽인 함정의 번호를 정확히 가리킨다
- 안 죽었으면 `-1`이다
- 두 함정이 동시에 닿으면 앞의 것을 가리킨다 *(정해두지 않으면 그리는 것이 깜빡인다)*

재미와 손맛은 검사가 못 본다. 그건 브라우저에서 직접 한다.

- 배포, 모바일 실기 확인 — 이 작업 다음
- 새 소리 — Re에서 가져온 다섯 개를 그대로 쓴다. 설정이 바뀌어도 클릭·실패·성공은 같다
