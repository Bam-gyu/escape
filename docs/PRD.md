## 1. 무엇을 만들고 있나

**감옥탈출류 마우스 피하기 팬 게임.** 원작은 YunoGT의 「감옥탈출 리마스터」다.
(https://vidkidz.tistory.com/155 에서 직접 해볼 수 있다)

죄수가 커서를 따라다닌다. 함정에 닿으면 즉사하고, 바로 다시 시작한다.
출구에 닿으면 다음 방으로 간다. 죽은 횟수가 쌓인다.

**습작이다.** 규칙과 장치는 원작을 따라 만들고, 그림·효과음·음악과 방 배치는 우리 것이다.
Re 프로젝트(`/Users/wa/Desktop/Game/Re`)가 리센느 팬 게임인 것과 같은 자리다.

### 원작을 직접 해보고 확인한 것

추측이 아니라 플레이해서 본 것만 적는다.

- 죄수가 커서에 **딱 붙는다.** 지연도 관성도 없고, 커서는 죄수의 발밑에 온다
- 함정에 닿으면 **즉사**한다. 손그림 해골이 뜨고 "다시"를 누르면 그 방을 다시 시작한다
- 시작할 때 **이름과 죄목**을 적는 수감 카드가 있다 (기본값 "범죄자 / 이름 자체가 죄")
- 게임 안내문이 스스로 "마우스 피하기 방식입니다"라고 밝힌다
- 1스테이지는 간수 둘의 빨간 시야 원뿔, 가운데가 뚫린 철창, 철창에 붙은 전기로 이루어져 있다
- 그림은 도트가 아니라 **굵은 검은 외곽선 손그림**이다

## 2. 이미 정해진 것 — 다시 논의하지 말 것

사용자와 합의가 끝난 사항이다. 바꾸려면 먼저 사용자에게 물어야 한다.

| 결정 | 내용 |
|---|---|
| 위치 | 습작. 규칙은 원작대로, 그림·소리·방 배치는 우리 것 |
| 보스 | **없다.** 원작에는 폭탄을 밀어 맞히는 보스 방이 있지만 뺐다 |
| 히든 맵 | 없다 |
| 이스터에그 이름 | 없다 |
| 방 수 | **미정.** 5개보다는 많이. 그래서 방을 늘리는 값이 싸야 한다 |
| 그림 | 손그림. **도트는 안 쓴다** — 32px 격자에 원작의 맛이 안 들어간다 |
| 소리 | Re 프로젝트에서 가져온다 |
| 바탕 | 웹. 유니티 안 쓴다 |
| 의존성 | **없다.** npm install도 빌드 도구도 안 쓴다 |

### 규칙을 하나로 합친 것

설계 초안에서는 벽을 "못 지나감", 철창을 "죽음"으로 나눴다. **둘 다 죽음으로 합쳤다.**

원작에서 철창에 닿자 즉사했고, 막히는 벽을 따로 두면 커서가 벽 안에 있을 때
죄수를 어디에 둘지부터 정해야 한다. 규칙이 하나면 판정 코드가 절반이 되고,
플레이어에게도 설명할 것이 없다.

방 밖으로 나가는 것만 예외다. 가장자리에서 붙잡는다.

### 되는 것 — 브라우저에서 직접 확인했다

- 수감 카드에 이름·죄목을 적고 들어간다
- 죄수가 커서에 붙는다. 판정은 발밑 반지름 7짜리 원 하나

### 안 된 것 · 모르는 것

| | |
|---|---|
| 그림 | **한 장도 없다.** 전부 색 도형으로 그리고 있다 |
| 모바일 터치 | 코드는 넣었으나 **실제 기기에서 안 봤다** |
| 죽음 화면 | 원작의 손그림 해골 대신 글자만 나온다 |
| 원작의 나머지 방 | **못 봤다.** 1스테이지에서 죽었고, 사람도 65~290번 죽고 깨는 게임이다 |
| 배포 | 안 했다. 로컬 서버로만 돌렸다 |

원작의 방을 눈으로 베끼는 건 포기했다. 대신 **장치를 베끼고 배치는 우리가 짠다** —
사용자와 합의한 방식이다.

## 5. 구조

```
src/rules/     규칙. 화면도 시간도 캔버스도 모른다. 여기만 검사하면 게임이 검사된다
  geometry.js    원↔사각형, 원↔부채꼴이 겹치는가
  hazards.js     시간을 넣으면 함정이 지금 어떤 모양인가
  room.js        죄수 자리, 죽었는가, 도착했는가
src/data/rooms.js   방 목록. 방을 늘리는 곳
src/view/      그리기와 소리. 규칙을 안 바꾸고 보여주기만 한다
  art.js         그림 목록 — 그림 갈아끼우는 자리
  render.js      그림이 있으면 그림, 없으면 도형
  palette.js     도형으로 그릴 때 쓰는 색
  audio.js       소리
src/main.js    화면 넘김, 죽음 세기, 입력
test/          검사 27개
art/           비어 있다. 여기에 png를 넣는다
audio/         Re에서 가져온 mp3 5개
```

### 설계의 핵심 둘

**하나. 그림과 판정을 분리했다.** 게임이 보는 것은 도형뿐이다. 그림은 위에 얹힌
장식이고, 게임은 그림이 있는지도 모른다. 그래서 그림이 없어도 돌고, 그림을 넣어도
게임 코드가 안 바뀐다. 근육 죄수가 화면의 4분의 1을 차지해도 판정 목록에 없으면
게임은 그를 모른다.

**둘. 방은 데이터다.** 방 하나 = 데이터 덩이 하나. 방을 늘리는 데 코드도 그림도 안 늘어난다.

## 6. 방 추가하기

`src/data/rooms.js`에 덩이를 하나 더 넣는다. **코드는 안 건드린다.**

방은 960×720. 왼쪽 위가 0,0이고 **y는 아래로 커진다.**

```js
{
    name: '세탁실',
    spawn: { x: 480, y: 690 },
    exit: { x: 440, y: 0, w: 80, h: 46 },
    hazards: [ ... ],
    props: [ ... ],
}
```

| 함정 | 값 | 하는 일 |
|---|---|---|
| `rect` | `x y w h` | 가만히 있는다. 벽과 철창 |
| `blink` | 위 + `period on` | `period`초마다 `on`초 동안만 죽인다. 전기 |
| `mover` | 위 + `dx dy period` | 제자리에서 그만큼 왕복 |
| `cone` | `x y radius spread from to period` | 간수 시야. **각도는 0이 오른쪽, 90이 아래쪽** |

`offset`(초)을 주면 시작 박자가 밀린다. 함정 여럿을 어긋나게 할 때 쓴다.
`art`에 이름을 적으면 그 그림으로, 안 적으면 색 도형으로 그린다.

**방을 넣었으면 `npm test`를 돌린다.** 검사가 대신 봐주는 것:

- 시작 자리가 15초 내내 안전한가 — 안 그러면 아무것도 안 했는데 죽는 방이 된다
- 출구에 설 수 있는 순간이 있는가 — **못 깨는 방을 막는다**
- 소품이 벽에 묻혀 영영 안 보이지 않는가 (실제로 이걸로 버그 하나 잡았다)

## 9. 걸리기 쉬운 것

**규칙 층에 화면 이야기를 넣지 말 것.** `src/rules/`는 캔버스도 DOM도 `window`도 모른다.
이게 깨지는 순간 검사가 브라우저를 요구하게 되고, 27개가 다 못 돌게 된다.

**함정에 상태를 들리지 말 것.** 지금은 시간만 넣으면 모양이 정해진다. 함정이 스스로
"내가 지금 켜져 있다"를 기억하기 시작하면, 죽고 다시 시작할 때 함정을 되돌리는 코드가
따로 필요해진다. 되감기도 건너뛰기도 안 되고, 검사에서 시간을 임의로 넣을 수도 없어진다.

**죽는 것이 도착보다 먼저다.** 순서를 바꾸면 출구 옆에 함정이 있는 방에서
죽으면서 통과하는 일이 생긴다. 검사가 잡는다.

**소품은 판정이 없다.** 게임이 `props` 목록을 아예 안 본다. 판정을 주고 싶으면
`hazards`로 옮겨야 한다.

**방에 들어서면 커서가 시작 자리에 올 때까지 기다린다**(`READY_RADIUS`, main.js).
이게 없으면 앞 방에서 커서가 있던 자리에 죄수가 튀어나와 그대로 죽는다.
자기가 뭘 잘못했는지 알 수 없는 죽음이라 이 장르에서 가장 나쁘다. 지우지 말 것.

**각도는 0이 오른쪽, 90이 아래쪽이다.** 화면 좌표라 y가 아래로 커진다.
간수가 아래를 보게 하려면 90 근처를 쓴다.

## 10. 다음에 할 일 — 순서대로

1. **그림 한 벌.** 15장 안팎. `player`와 `guard`부터 넣으면 화면이 단번에 달라진다.
   사용자가 그린다. 그때까지 도형으로 계속 굴러간다
2. **방을 5개 위로.** 함정 종류를 하나씩 얹어 어렵게 만든다.
   지금 넷(`rect` `blink` `mover` `cone`)으로도 조합이 남았다
3. **죽음 화면의 손그림 해골.** 원작의 인상이 여기서 나온다
4. **모바일 터치 확인.** 코드는 있으나 실제 기기 미확인
5. **배포.** 정적 파일이라 그대로 올라간다

### 새 함정을 만들 때

`hazards.js`의 `shapeAt`에 `case`를 하나 더하고, `render.js`가 그릴 줄 알게 하면 된다.
**하나를 만들면 모든 방이 그걸 쓴다.** 원작이 뒤로 갈수록 어려워지는 방식이 이것이다.

`shapeAt`은 모르는 종류를 만나면 조용히 넘어가지 않고 터진다. 데이터에 오타를 냈을 때
화면에 아무것도 안 나오고 끝나면 방이 왜 쉬운지 알 수가 없기 때문이다.
